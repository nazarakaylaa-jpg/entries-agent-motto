## The entry

> "I can read minds. Yours is just 47 tabs you forgot to close."

## How it works

`main.ts` writes the one-line motto (60 characters, a single line, punchline at the end) to `/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
